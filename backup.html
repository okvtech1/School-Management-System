Instructions

  1. JSON is the complete, exact copy of every record — this is what you'd hand to OKV Technology (or any developer) to fully restore or migrate your data. Keep it somewhere safe (Google Drive, email to yourself, a USB drive).
  2. CSV is a flat, spreadsheet-friendly copy — one row per record, with each record's details packed into a single "Details" column as text. It's easy to open in Excel/Google Sheets to eyeball your data, but it's not meant to be re-imported directly.
  3. To restore individual data types (Students, Staff, etc.) day-to-day, use the CSV Import button already on each of those pages — it accepts the same column layout you'd export from there. This Backup tab is for a full, whole-organization safety copy, not routine data entry.
  4. Restoring a full JSON backup (e.g. after moving to a new plan, or in a disaster-recovery situation) isn't self-service yet — contact OKV Technology with the JSON file and they can load it back into a fresh copy of your organization's spreadsheet.
  5. We'd suggest generating a fresh backup every so often — right after a busy exam period, end of term, or before any big data cleanup — so you always have a recent copy.
Passwords are never included in a backup — user accounts export with name/username/email/roles only. If you ever need to restore users, they'll need to reset their password afterward via "Forgot password" on the login page.
